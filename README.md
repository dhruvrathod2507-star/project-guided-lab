# Project Guided Lab

A hands-on project repository for **B.Tech Cyber Security** students to build real-world skills in **Data Engineering**, **AI/ML Engineering**, and **Applied Cyber Security**.

Each project is self-contained with step-by-step guides, starter code, datasets, and checkpoints so you can learn by doing.

---

## Available Projects

| # | Project | Domains Covered | Difficulty | Duration |
|---|---------|----------------|------------|----------|
| 01 | [Network Threat Detection Pipeline](projects/01-network-threat-detection-pipeline/) | Data Eng + AI/ML + Cyber Security | Intermediate | 6-8 weeks |

---

## How to Use This Repo

1. **Fork** this repository to your own GitHub account
2. **Clone** your fork locally
3. Navigate to the project folder and follow the `README.md`
4. Complete each phase sequentially — each builds on the previous one
5. Commit your work after each phase with meaningful commit messages
6. Push your completed project for review/submission

## Prerequisites

- Python 3.9+ installed
- Basic Python programming (variables, functions, loops, file I/O)
- Basic understanding of networking concepts (IP, TCP/UDP, ports)
- Git basics (clone, add, commit, push)
- A code editor (VS Code recommended)
